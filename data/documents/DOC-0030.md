Subject: Weekly BETA Queue Report Uses Decision Fields

Decision: From 2026-10-19, DEMO-PROGRAM-BETA's weekly queue report will use a decision-focused layout. Each entry provides a locating reference, subsystem, owning team, question requiring a decision, dependency role, next action, and next discussion date.

Add a schedule-change column for a moved appointment or a changed receiving role. Preserve the prior appointment alongside its replacement so that the reader can understand why a discussion moved. The report layout must not include workload figures, totals, or a copied snapshot of record categories.

The structures discussion at the review staffing meeting informed this layout. Its working folder is located through DEMO-AIR-0002 and ISSUE-0150; TASK-0395 may identify a related paper. Those references illustrate the arrangement of fields rather than an entry selected for the weekly report.

The records editor should return entries that contain only a short topic label. Ask the submitting coordinator to state the decision needed and the role responsible for obtaining it. If a dependency role is unknown, the owning team must provide a contact plan and date.

Implementation: PERSON-0006 will circulate the blank layout on 2026-10-19. The program chair will review its clarity on 2026-10-26, using questions about field meaning rather than tallying the queue. Retain any format correction with the dated layout so station editors use the same headings.

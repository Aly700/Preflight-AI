Task Labels, Subsystem Labels, and Blank Fields
Desk reference dated 2026-10-15
Prepared by Demo Worker 0001 for Demo Team 01

TASK STATUS — exact spellings

todo: The task's queued category. Do not substitute the issue term open.

in_progress: The task workflow category for activity underway. Specify task when the same wording might be read as an issue field.

awaiting_review: The task review category. Its completion timestamp is empty. A booked conversation is not evidence of this value.

completed: The task completion category. Its completion timestamp is populated. This value does not automatically give the parent issue the status closed.

blocked: The task category for an impediment in its tracking workflow. A paper reminder is not evidence that this value applies.

TASK KIND — separate from status

review: A category label for review-related tracking.
investigation: A category label for investigation-related tracking.
documentation: A category label for documentation-related tracking.
inspection: A category label preserved from the task vocabulary.
rectification: A category label preserved from the task vocabulary.

These terms identify entries for coordination. None supplies a physical procedure, a completion claim, or a reason to change another field. Put the kind in the kind box and the question in the question box.

SUBSYSTEM — issue grouping labels

hydraulics: Use this exact grouping word.
avionics: Use this exact grouping word.
electrical: Keep distinct from avionics.
cabin: Use the recorded grouping, not a guessed alternative.
structures: Retain the plural spelling.
controls: Retain the plural spelling.

A task kind and a subsystem describe different fields. A subject heading may mention both, but the routing slip must keep them separate so a coordinator can ask for the intended grouping.

ISSUE AND PRIORITY REMINDER

open, in_progress, blocked, reopened, closed are issue statuses. Unresolved means any issue status other than closed. A reopened issue has closure then reopening history and an empty current closure timestamp.

low, medium, high are priority labels. They do not describe task kind or substitute for an issue status.

BLANKS AND REFERENCES

assigned_person_id left blank: No person assignment is recorded in that field. Do not fill the gap with the meeting recorder's name. An assigned person, when present, belongs to the task's assigned team.

A question using ISSUE-0011, DEMO-AIR-0006, or TASK-0030 still needs a correspondence recipient. This sheet does not supply that recipient.

Editing note: Read underscores aloud as part of the field spelling when dictating a correction; preserve the exact written label.

POLICY
Effective date: 2026-09-28
Custodian: PERSON-0033, TEAM-0003
Scope: Administrative handling of suspected duplicate issue entries.

1. Compare the questions and scope before proposing a merge. Similar subsystem labels or similar titles are not enough. The queue coordinator records why the entries appear to describe the same coordination concern and asks the originating desks to resolve any difference in scope.

2. Keep both issue IDs on the cover sheet. Mark which entry will carry the continuing discussion and which reference leads to the originating submission. Never erase an older reference merely because its paper is filed behind the keeper.

3. Write a merge note with the date, participating desk roles, reason for choosing the keeper, and destination of any remaining administrative action. Preserve each originating question in its received form so that a later reader can reconstruct the decision.

4. Use the keeper and origin tabs introduced by the program's duplicate-note trial. File the merge rationale behind the keeper tab and the source material behind origin. The tab names describe filing relationships, not a record's current category.

5. Escalate disputed scope to the queue chair before combining the papers. ISSUE-0128 and TASK-0344 are locating references for the hydraulics desk layout; no duplicate partner is asserted by this policy.

Revision note: The trial's keeper and origin tabs are retained, with an explicit requirement to preserve both issue references.

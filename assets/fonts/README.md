# Fonts for the scanned-document renderer

Three font families used by `scripts/render_scans.py` to draw the fictional documents as
scanned-looking pages. Each is licensed under the SIL Open Font License 1.1; the licence
file sits next to its font. Copied unchanged from the google/fonts repository at commit
`5bb28733cec313b63fbd415b574b5ae35c8aa8b8`.

Defect found and fixed during this check:
  The Workers runtime rejects fetch(..., {redirect: 'error'}):
    TypeError: Invalid redirect value, must be one of "follow" or "manual"
  Both forwarded routes returned 502 in ~2 ms until server/forward.mjs switched to redirect: 'manual'
  and refuses any 3xx with the fixed 502 (regression test added in tests/proxy.test.mjs).
  AbortSignal.any, AbortSignal.timeout and Response.json are available in the runtime (probe Worker).

Still required before the demo is live:
  wrangler login; wrangler secret put API_BASE_URL; wrangler secret put PREFLIGHT_ACCESS_KEY; npm run deploy.
  Workers cannot fetch a bare IP address: API_BASE_URL must be an https URL with a hostname whose
  certificate is valid for that hostname.
